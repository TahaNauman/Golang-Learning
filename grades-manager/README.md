# Student Grade Manager

A command-line application built in Go for managing student grades and calculating grade statistics.

## Features

- Store student names and their grades.
- Calculate average grades.
- Find the highest and lowest grades.
- Calculate the range between the highest and lowest grades.
- Convert numerical averages into letter grades.

## Prerequisites

- Go installed on your system.

## How to Run

Navigate to this directory and run:

```bash
go run .
```

Follow the terminal prompts to manage student grade information.

## Concepts Practiced

- Structs and slices for representing students and their grades
- Functions with parameters and return values
- Multiple return values
- Named return values
- Loops and conditional statements
- Calculating averages, minimums, maximums, and ranges

## Purpose

This project strengthened my understanding of functions, data processing, and returning multiple values in Go while building a simple grade-management tool.
