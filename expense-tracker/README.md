# Expense Tracker CLI

A command-line application built in Go for recording and managing expenses.

## Features

- Add expenses with an amount and description.
- View recorded expenses.
- Edit existing expenses.
- Delete expenses.
- Calculate and display expense totals.

## Prerequisites

- Go installed on your system.

## How to Run

Navigate to this directory and run:

```bash id="6x0jfn"
go run .
```

Follow the interactive menu to manage your expenses.

## Concepts Practiced

- Structs for representing expenses
- Slices for storing and managing records
- Maps and loops for aggregation
- Numeric input parsing with `strconv.ParseFloat`
- Functions and conditional logic
- Basic input validation

## Purpose

This project strengthened my understanding of structs, slices, numeric data handling, and aggregation while building a practical CLI application.
