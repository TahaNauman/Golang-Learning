# Number Guessing Game

A command-line game built in Go where the player tries to guess a randomly generated number within a limited number of attempts.

## Features

- Three difficulty levels: Easy, Medium, and Hard.
- Different number ranges and attempt limits for each difficulty.
- Random number generation.
- User input and guess validation.
- Feedback to help the player determine whether their guess is too high or too low.

## Difficulty Levels

| Difficulty | Number Range | Attempts |
|---|---:|---:|
| Easy | 1–50 | 10 |
| Medium | 1–100 | 7 |
| Hard | 1–500 | 5 |

Medium is the default difficulty.

## Prerequisites

- Go installed on your system.

## How to Run

Navigate to this directory and run:

```bash
go run .
```

Follow the prompts in the terminal to play.

## Concepts Practiced

- Variables and data types
- Loops and conditional statements
- Switch statements
- Functions and variable scope
- Random number generation
- User input and basic validation

## Purpose

This project was an introduction to Go's syntax and fundamental programming concepts through a small, interactive CLI application.
