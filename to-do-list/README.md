# To-Do List CLI

A command-line task manager built in Go that lets users manage their tasks directly from the terminal.

## Features

- Add new tasks.
- View the task list.
- Mark tasks as completed.
- Edit existing task titles.
- Delete tasks.
- Handle user input and validate task selections.

## Prerequisites

- Go installed on your system.

## How to Run

Navigate to this directory and run:

```bash
go run .
```

Use the interactive menu to manage your tasks.

## Concepts Practiced

- Structs for representing tasks
- Slices for storing and modifying collections
- Functions and control flow
- Reading user input with `bufio.Scanner`
- Converting and validating input with `strconv.Atoi`
- Adding, editing, completing, and deleting slice elements

## Purpose

This project helped me understand how to model data using structs and manage collections with slices while building an interactive CLI application.
